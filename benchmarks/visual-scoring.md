# Visual Scoring — 六维加权评分体系（v2.1.0）

评分不允许用"动效数量/粒子数量/镜头数量"衡量视觉质量。每个维度 0–100 分，
加权总分 100；技术正确性是硬门槛（一票否决项见 accuracy gate）。

| 维度 | 权重 | 评分要点 |
|---|---:|---|
| Technical Accuracy | 25% | 规范符合度、事实可溯源、无 TEACHING 误标 |
| Visual Creativity | 20% | 构图/隐喻/方向独创性；是否逃出方框箭头套路 |
| Motion Design | 20% | 运动语言六问、节奏、缓动、信息编码 |
| Storytelling | 15% | hero moment、场景推进、注意力引导 |
| Interaction | 10% | 契约完整性 + 可探索性（参数/场景/点击解码） |
| Code Quality | 10% | 契约、单一时间源、确定性、可访问性基线 |

**通过阈值**：Technical Accuracy ≥ 90 且 Visual Creativity ≥ 80 且
Motion Design ≥ 80 且 加权总分 ≥ 85。

**N/A 规则**：不适用的维度记 N/A 并从权重中剔除后重新归一化
（例：纯静态结构图 Motion Design 记 N/A → 其 20% 按比例分给其余维度）。
不要求 3D/粒子/镜头/复杂转场——**用最合适的视觉方法准确而有吸引力地表达知识点**
才是评分核心；优秀的静态结构图同样可以通过验收。

**流程**：先技术门禁（validate_* + 浏览器套件），后本评分；评分者须给出逐维证据
（截图路径/测试输出）；AI 评分须标注身份，发布前建议人工复核。不得伪造评分。
